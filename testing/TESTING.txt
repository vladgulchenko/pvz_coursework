ЧТО ДОБАВЛЕНО

AdministrationTests: смена пароля; сохранение истории при деактивации;
запрет повторного использования логина; согласованность сеанса после
ошибочного/успешного изменения собственных данных; самостоятельная
деактивация при наличии второго администратора; переименование и удаление мест.

AtomicityTests: откат всей регистрации при сбое начальной истории;
откат обоих путей приёма к возврату и завершения возврата;
откат замены позиций, получателя и размещения при сбое вставки позиции.
Ошибки вызываются настоящими SQLite-триггерами RAISE(ABORT).

ServiceBoundaryTests: после выхода запрещены чтение и запись защищённых
данных; обязательные сведения регистрации проверены без частичных записей.
MigrationTests: текущая EF-модель не требует незаписанной миграции.

WPF-прогон дополнительно проверяет поиск/фильтры, отключение редактирования
номера и дат, повторное сохранение созданных записей и освобождение UI
после ошибки. Проверка перезапуска запускает два процесса настоящего App:
первый сохраняет весь жизненный цикл заказа и штатно закрывается,
второй входит по сохранённым учётным данным и перечитывает заказ, позиции,
статус, отсутствие размещения и четыре записи истории.

Рабочая БД пользователя не открывается. Для проверок используются уникальные
временные каталоги. Пароль WPF-прогона случайный, передаётся дочерним процессам
через окружение и не выводится в отчёт. Данные и изображения вымышленные.

ВОСПРОИЗВЕДЕНИЕ

Из корня code в Windows PowerShell:

powershell -NoProfile -ExecutionPolicy Bypass -File testing/Run-Tests.ps1

Параметр -ExportEvidence дополнительно обновляет файлы testing/evidence,
которые можно приложить к записке. Без него результаты остаются только
в игнорируемом TestResults/<идентификатор запуска>.
Параметр -PackageCache задаёт необязательный путь локального кэша NuGet.
Параметр -SkipRestore допустим только после успешного восстановления
зависимостей решения и tools/Pvz.Smoke.

Прямой запуск без сценария:

dotnet restore Pvz.sln --locked-mode
dotnet restore tools/Pvz.Smoke/Pvz.Smoke.csproj --locked-mode
dotnet build Pvz.sln -c Release --no-restore -warnaserror
dotnet build tools/Pvz.Smoke/Pvz.Smoke.csproj -c Release --no-restore -warnaserror
dotnet test tests/Pvz.Tests/Pvz.Tests.csproj -c Release --no-build --no-restore
dotnet tools/Pvz.Smoke/bin/Release/net8.0-windows/Pvz.Smoke.dll
dotnet tools/Pvz.Smoke/bin/Release/net8.0-windows/Pvz.Smoke.dll --startup
dotnet tools/Pvz.Smoke/bin/Release/net8.0-windows/Pvz.Smoke.dll --restart
dotnet tools/Pvz.Smoke/bin/Release/net8.0-windows/Pvz.Smoke.dll --instance-lock
